Multiplayer

Checking the server…

Race friends online, like a LAN party. One of you opens a room and shares its code; the others type it in or pick the room from the list. Everyone needs their own copy of the game, and the same version. Rooms are only for finding each other: your game files stay in your browser.

Relay server: not set

Online play goes through a small relay server that you or a friend runs (see the README). Enter its address.

    Graphics

    Game settings

    The slider sets the view distance: how far you can see before the fog. These are the game's own Graphics options, kept in your profile. Change them here or in the game's Options.

    A quality preset sets the options above and below; change them after. In a race, F3 switches between this and the original look.

    Profiles

    Your profiles, settings and records are kept in this browser. Clearing the browser's site data erases them, so export a backup to keep them safe.

    Important: leave the game with the X on the main menu. Closing the tab (instead of using the X) right after a save can still lose that save.

      About this project

      The game engine is a Rust program compiled to WebAssembly that draws with WebGPU. Your game files are read into memory in your browser and never leave your computer. Your profile and records are saved in the browser.

      The Multiplayer tab is the one part that talks to a server: a small relay that passes the game's network packets between players, and never sees your game files.

      Built on openmcm2 0.2.1 by crspytopgn, which provides the engine, physics, file formats and menus. The movie decoder is a port of FFmpeg's Indeo 5 decoder by Maxim Poliakovski (LGPL). Ground materials are from ambientCG (CC0). The code is MIT or Apache-2.0 licensed.
