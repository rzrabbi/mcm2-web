# OpenMCM2 logo

The knobby tyre logo, an original drawing (nothing from the Motocross
Madness 2 box art or logo). Colours: ink `#1d2b3a`, orange `#e8692a`,
tile `#f4f6f8`. Lettering is Rubik Bold (SIL Open Font License),
turned into outlines.

- `openmcm2.svg`, `openmcm2-dark.svg`: the full logo, for light and dark backgrounds.
- `app-icon.svg`: the app icon (1024 grid); `app-icon-small.svg` is the same tyre filling the tile, for 64 px and below.
- `icon-256.png`: window icon for the game.
- `openmcm2.ico`: Windows .exe icon (16 to 256 px), added by each crate's `build.rs`.
- `social-preview.png`: 1280×640 image for the GitHub repo's social preview (Settings → General).
